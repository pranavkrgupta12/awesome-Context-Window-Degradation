# GitHub Implementations

These repositories are implementation resources relevant to long-context LLMs, retrieval, and evaluation.

## 1. LongBench

A benchmark-oriented project for evaluating long-context understanding.

https://github.com/THUDM/LongBench

## 2. L-Eval

A long-context language-model evaluation project.

https://github.com/OpenLMLab/l-eval

## 3. RULER

A benchmark for evaluating long-context language models across a broader range of tasks.

https://github.com/NVIDIA/RULER

## 4. Haystack

Implementation framework for retrieval, question answering, and RAG pipelines.

https://github.com/deepset-ai/haystack

## 5. LlamaIndex

Implementation framework for retrieval and data-connected LLM applications.

https://github.com/run-llama/llama_index

> **Selection note:** Before submission, check repository activity, documentation, reproducibility, and licensing. Prefer implementations directly connected to the claims or methods discussed in the paper.
