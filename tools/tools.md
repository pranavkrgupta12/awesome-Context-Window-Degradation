# Tools and Libraries

## 1. Hugging Face Transformers

A widely used library for transformer models and experiments involving language models.

https://github.com/huggingface/transformers

## 2. vLLM

A high-throughput inference engine useful for running and evaluating large language models.

https://github.com/vllm-project/vllm

## 3. LangChain

A framework for composing LLM applications, including retrieval and long-document workflows.

https://github.com/langchain-ai/langchain

## 4. LlamaIndex

A framework for connecting LLMs to external data and retrieval pipelines.

https://github.com/run-llama/llama_index

## 5. Haystack

An open-source framework for search, retrieval, question answering, and RAG systems.

https://github.com/deepset-ai/haystack
